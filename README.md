## 中文

Mai C1 Edit Thick Version 是我们自己的 Mai C1 Edit 的粗腿版本。保留收窄后的胸前布料、调整后的前片、缩短的 Obi 和原有上半身造型，提供 10%、15%、20% 三档腿部加粗。袜子与绑腿随腿部轮廓同步调整。

每档均提供 Pubic Hair（有毛）和 No Pubic Hair（无毛），共六个独立安装包。同一腿围档位的两种毛发版本，服装与身体模型一致，仅附加毛发不同。

### 安装方法

1. 关闭游戏，选择一个版本并下载 ZIP。
2. 打开 Fluffy Mod Manager，选择 Street Fighter 6。
3. 添加 ZIP，启用对应 MOD。
4. 启动游戏，选择 Mai C1。

切换腿围、毛发或 Thong 组合前，先停用当前 Mai C1 MOD。

### 主要特点

- 提供 10%、15%、20% 三档腿部加粗。
- 袜子与绑腿随腿部轮廓同步调整。
- 保留 Mai C1 Edit 的上半身与服装造型。
- 每档均有有毛、无毛版本，共六个独立安装包。
- 保留原有贴图、501 根骨骼与顶点权重。

### 使用要求

- PC 版 Street Fighter 6。
- 游戏中可使用 Mai。
- Fluffy Mod Manager。

## English

Mai C1 Edit Thick Version adds thicker legs to our Mai C1 Edit. It retains the narrower top panels, revised tare, shorter Obi and existing upper-body shape, with 10%, 15% and 20% leg options. The socks and leg wraps follow the revised leg shape.

Each thickness has Pubic Hair and No Pubic Hair variants, for six standalone packages. Within the same thickness, both hair variants use identical clothing and body meshes; only the added hair differs.

### Installation

1. Close the game and download one ZIP.
2. Open Fluffy Mod Manager and select Street Fighter 6.
3. Add the ZIP and enable the mod.
4. Launch the game and select Mai C1.

Disable the current Mai C1 mod before switching thickness, hair or thong options.

### Main features

- 10%, 15% and 20% leg-thickness options.
- Socks and leg wraps adjusted with the leg shape.
- Retains the upper-body and costume edits from Mai C1 Edit.
- Pubic Hair and No Pubic Hair options at each thickness, for six standalone packages.
- Original textures, 501-bone rig and vertex weights retained.

### Requirements

- Street Fighter 6 on PC.
- Access to Mai in-game.
- Fluffy Mod Manager.
